# Nebula
A small interpreted scripting language
## Project Status
Nebula is an early-stage programming language, currently in developmen with new features planned. While it is not yet production-ready, it is open for experimentation and feedback.
### Currently Implemented:
  - Blocks
  - Variables
  - While loops
  - Conditionals
  - Simple printing

### Planned Features:
- Arrays (In Progress)
  - Still must implement priting and variable indexing 
- Strings
- For loops
- Functions
- Fully featured I/O
- Pointers

Official documentation is not yet available, but example programs serve as a reference for usage. Feedback is welcome!
